# Hackathon Scout 🏆

تابلوی تمیز هکاتون‌ها: رویدادهای آینده **بالا**، تمام‌شده‌ها **پایین + مُهر EXPIRED**.
پنل ادمین هم یک **پارسر هوشمند مارک‌داون** دارد: گزارش را paste می‌کنی → JSON تمیز تحویل می‌گیری.

## ⚡ اجرای سریع با فقط یک کلید (۲ دقیقه)

تنها چیزی که لازم داری یک **Cloudflare API Token** است.

**۱. توکن را بساز:**
`Cloudflare Dashboard → My Profile → API Tokens → Create Token → قالب Edit Cloudflare Workers`

**۲. توکن را در پروژه بگذار:**
```bash
cp .env.example .env
# فایل .env را باز کن و توکن را جای PASTE_YOUR_TOKEN_HERE بگذار
```

**۳. دیپلوی تک‌دستوری:**
```bash
bash deploy.sh
```

همین. اسکریپت خودش این کارها را می‌کند:
- دیتابیس D1 می‌سازد + جدول را اعمال می‌کند
- حافظه KV می‌سازد
- ۷ رویداد نمونه را seed می‌کند
- ورکر را دیپلوی می‌کند (`GET/POST /api/events` + کرون روزانه)

**۴. فرانت را وصل کن (۱ دقیقه):**
پوشه را به گیت‌هاب push کن → در Cloudflare برو `Pages → Create → Connect to Git` → تنظیمات:
- Build command: *(خالی)*
- Output directory: `/`

تمام شد. سایت بالاست ✅

## 🖥️ پیش‌نمایش روی سیستم خودت (بدون اینترنت)

```bash
npm run dev
# بعد باز کن: http://localhost:8080
# پنل ادمین: http://localhost:8080/admin.html
```

## 🧠 پنل ادمین چطور کار می‌کند؟

1. `admin.html` را باز کن
2. متن مارک‌داون گزارش را paste کن → دکمه **Parse**
3. پارسر خودش این‌ها را بیرون می‌کشد: تیتر، برگزارکننده، وضعیت، نوع، بازه برگزاری، تاریخ شروع، ددلاین، جایزه (متن + عدد)، نیازمندی‌ها، لینک‌ها
4. اگر چیزی اشتباه بود همان‌جا دستی اصلاح کن
5. **Download events.json** → دیتابیس را آپدیت کن (یا در حالت لوکال جایگزین `data/events.json` کن)

## 📁 ساختار پروژه

```
index.html          → تابلوی عمومی
admin.html          → پنل ادمین + پارسر هوشمند
assets/js/parser.js → موتور پارسر (قابل تست)
assets/js/app.js    → منطق تابلو (آینده بالا / منقضی پایین)
data/events.json    → دیتای فعلی سایت
worker.js           → API ورکر (D1 + KV + کرون)
deploy.sh           → دیپلوی تک‌دستوری (فقط توکن می‌خواهد)
```

## 🔑 متغیر محیطی

| کلید | از کجا | کاربرد |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | My Profile → API Tokens | تنها کلید لازم برای دیپلوی |

> ⚠️ فایل `.env` را هیچ‌وقت commit نکن (در `.gitignore` هست). توکن را در چت فوروارد نکن.

## ❓ مشکل خوردی؟

- `CLOUDFLARE_API_TOKEN is missing` → فایل `.env` را ساختی؟ توکن داخلش است؟
- خطای دسترسی wrangler → از قالب **Edit Cloudflare Workers** برای توکن استفاده کن، نه Read Only.
- سایت بالا آمد ولی دیتا قدیمی است → `admin.html` را باز کن، JSON جدید دانلود کن و POST کن (دستورش در `README-DEPLOY.md` بخش C).
